Model rules

The origin and all links stay up. Each activation updates one AS, which reads its neighbor’s current advertisement and publishes its own selection immediately. Other ASes retain their selected paths until their next activation. The model tracks selected advertisements, so a displayed path can temporarily include a suffix the neighbor has since stopped selecting.

The model tests stability by asking whether all three ASes would keep their routes if activated next. It detects a repeating execution when both the three selected routes and the next scheduled activation recur.
