## Worked checks

- **DHCP and DNS.** The laptop uses Ethernet broadcast, IPv4 `0.0.0.0` to `255.255.255.255`, and UDP 68 to 67 for its first request. Once it has a lease, its local destination for the DNS query is `192.0.2.53`. A cache miss produces the illustrative root, TLD, and authoritative queries. A second local client can get an answer from the resolver cache while the A record is still valid.
- **Local delivery.** The first 26 bits of `192.0.2.34`, `192.0.2.53`, and `192.0.2.1` match. The DNS query uses the resolver's MAC address. The web SYN uses the gateway's MAC address and retains `198.51.100.70` as the IP destination.
- **Market and Weather.** The original and compressed tables both send `.63` to Market, `.64` and `.95` to Weather, `.96` and `.127` to Market, and `.128` to the uplink. The destination `.70` matches the default and both the Market and Weather rules that cover it. The `/27` is the longest match. Removing it changes 32 decisions, for last octets 64–95.
- **Quiz 1 (2025), Q9–Q10.** `128.83.2.154` goes to R3. Keep `128.83.0.0/24` and `128.83.1.0/24` and replace the two R3 prefixes with `128.83.2.0/23`. Above those four subnets, the first drop is `128.83.4.0`. Changing R3's second `/24` to `128.83.4.0/24` leaves two blocks whose smallest common covering prefix is `128.83.0.0/21`. It includes addresses the table previously dropped, such as `128.83.3.0`. One R3 entry alone would change a forwarding decision.
- **Quiz 1 (2024), Q1–Q4.** The reply is `19.16.1.1:80` to `100.12.0.5:50000`. The SYN needs the right destination port when sent, which the application can get from a convention, a URL, configuration, or a discovery mechanism. At a closed TCP port an ordinary host responds with a reset, provided the SYN reaches it and the response can get back. A concurrent second connection to the same server and port can keep the two IP addresses and use a different client port, such as 50001.
- **Address allocation.** A conventional `/26` has 62 assignable addresses, enough for 40 laptops and a gateway. A `/27` has 30, enough for 20 laptops and a gateway. One valid division of an allocated `192.0.2.0/25` gives `192.0.2.0/26` to the first LAN and `192.0.2.64/27` to the second. The remaining `192.0.2.96/27` belongs to the same allocation. If it is unused, Returno's router can discard traffic for it so that it cannot loop back toward Homer through the default route. Outbound traffic uses a gateway in Cooville, then FeatherNet, then a route toward the server. Return traffic needs a route toward Buffering Heights and the advertised village prefix, followed by the appropriate local route in Cooville. A second path may require advertising or installing a separate, more specific route.
- **Network detective.** Capture at the resolver's interface and look for the client query, then look for any upstream DNS query and reply. A request visible at the laptop and absent at the resolver suggests a delivery problem. A query received at the resolver followed by an unanswered outgoing query suggests trouble beyond the resolver. For a missing SYN-ACK, a capture at the server can distinguish a SYN that never reaches it from a SYN that arrives and elicits a reply which fails to return. A SYN that does arrive with no reply requires checking the listener and local packet filtering.

The quiz supplies neither operators' addresses nor routing configuration for the real Internet side of Wingternet. The worked example chooses a local resolver and static, preinstalled forwarding entries. The mechanics of distributing routes, and how unmodified browser and transport timers behave on FeatherNet, remain separate questions.
