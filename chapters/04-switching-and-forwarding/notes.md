## Exercises and worked checks

- **Break this.** Adapted from [Quiz 1 (2025), Q16, PDF page 8](../../assets/quiz1-2025.pdf#page=8). The copy starting toward 9 follows 5 → 9 → 2 → 5. Switch 5 records L on the port toward 2 when that copy returns. The copy traveling the other way can overwrite the entry again. A destination that stays unknown is flooded in the same way even if the destination MAC is unicast. MAC learning uses the source, so it cannot create a destination entry for a silent address just because it appears as a destination.
- **What if the path is supposed to be shortest?** Adapted from [Quiz 1 (2025), Q21, PDF page 10](../../assets/quiz1-2025.pdf#page=10). Any three-switch spanning tree keeps two sides of the triangle, so the pair sharing the blocked side gets a path of length two despite the original one-hop cable. Changing the root can change which side is blocked, but some pair still has a detour.
- **Check the clock.** Adapted from [Final (2024), Q12, PDF page 7](../../assets/cs356-final-2024.pdf#page=7). The unique path in a settled tree is the same sequence of links in reverse. Its total is symmetric under the stated symmetric link delays. If forwarding moves to a different tree while an exchange is in progress, a request crossing 5 → 2 → 9 can receive a reply on 9 → 5. Link symmetry alone then supplies no equality between the two path totals. The failure might also prevent either message from arriving.
- **Network detective.** New exercise. Inspect the MAC entry for G at 5 and check whether the topology change invalidated that old port mapping. Control messages reaching 5 on a cable do not themselves teach the bridge where G is or establish that data is allowed on that cable. A broadcast returning on another port is consistent with an active cycle. Check the forwarding state on both ends of each inter-switch cable and distinguish a circulating copy from a fresh retransmission by the source.
- **Related quiz topology.** [Quiz 1 (2025), Q18–Q20, PDF page 9](../../assets/quiz1-2025.pdf#page=9) has a diagram of four routers on a square with one attached host at each router. The core links have 100 Mbps and $10 costs except R2–R4, which has 5 Mbps and $1 cost. The diagram and differing routing objectives belong with the next chapter's routing discussion.
